# HCI - Flutter Mobile Application

## Overview

This repository contains the initial setup for a Flutter mobile application developed as a university project. The project is currently in its foundational stage with a clean, standard Flutter project structure ready for future development.

## Project Status

**Current Phase:** Initial Setup

The application requirements, features, and UI designs will be defined and implemented in upcoming development phases. This initial commit establishes the project foundation and development environment.

## Prerequisites

- [Flutter SDK](https://docs.flutter.dev/get-started/install) (3.12+)
- [Android Studio](https://developer.android.com/studio) or Android SDK with emulator configured
- A code editor (VS Code / Kiro recommended)

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/kavindu-maduhansa/HCI.git
   cd HCI
   ```

2. Install dependencies:
   ```bash
   flutter pub get
   ```

3. Run the application:
   ```bash
   flutter run
   ```

## Project Structure

```
lib/
  main.dart          - Application entry point
test/
  widget_test.dart   - Widget tests
android/             - Android platform configuration
ios/                 - iOS platform configuration
web/                 - Web platform configuration
windows/             - Windows platform configuration
linux/               - Linux platform configuration
macos/              - macOS platform configuration
pubspec.yaml         - Dependencies and project metadata
```
